# Noteable

Made by KBM for our class project. Jot down a thought, sketch something, or keep track of class notes.

## Open it up

[Download Noteable (.zip)](https://github.com/GitTTAM/Noteable/archive/refs/heads/main.zip), then unzip it. You can also pick Code > Download ZIP on GitHub.

Open preview.html in the Noteable-main folder. Try the phone, 14-inch laptop, or 24-inch monitor view. Want the whole browser window? Click Use without frame, or open index.html instead.

Keep the files and fonts folder together. No install, server, or .env needed.

## Make a note

Cornell notes is ready to go when you open the app. Put questions or key words in Cues, write in Notes, and wrap things up in Summary. On a phone, these sections stack one below the other.

The Start from menu also has To-do list and Class notes. Each starts with its own bold color pair. Click a color circle to change it.

Type something, then click Tear off & save. Ctrl + Enter saves a new note too. It lands in Inbox, and a fresh Cornell note is ready. Your draft saves as you type, so you can come back to it.

New field adds a section. Change its Field name to whatever you need, like Questions or Tasks. In My notebook, fields with the same name share a column. The name suggestions help you keep things together.

Click Draw to sketch with a mouse, finger, or stylus. Click Type to write again. Both stay saved. Undo stroke removes your last drawn line.

## Find it again

Head to My notebook to search or open a note. You can pin it or change its collection, which works like a folder. Click Save changes when you're done editing. Closing the editor first drops those edits.

Deleted something by mistake? Click Undo right away, or go to Recently Deleted and click Restore. Your text, sketches, collection, and reminder come back together.

Want another template? Set up a note with the fields and colors you like, save it, then open it and click Save as template. Give it a name. It'll show up under Start from with the same layout and empty fields, ready to use again.

## Set a reminder

Click Add a reminder at the top right of your note. Pick the date and time you want. It starts at right now, so change it before saving.

Reminders show inside Noteable while it's open or when you come back. They won't pop up while the page is closed. You can find them under Reminders and mark them done there.

## A few things to know

Sign in and Sign up are just demo forms. Use made-up details if you try them. They don't create accounts, send anything, or save what you type.

Your notes stay in this browser on this device. They don't sync anywhere. Clearing browser data deletes your notes, drafts, templates, and Recently Deleted notes.

Export notes is there for later. Clicking it doesn't do anything yet.

Press N to jump to Quick capture when you're not typing. Escape closes a popup. Help / FAQ has a quick rundown if you get stuck.

The font is IBM Plex Mono. Its license lives in fonts/OFL.txt.
