# Noteable

Made by KBM for our class project. Jot down a thought, sketch something, or keep track of class notes.

## Open it up

[Download Noteable (.zip)](https://github.com/GitTTAM/Noteable/archive/refs/heads/main.zip), then unzip it. You can also pick Code > Download ZIP on GitHub.

Open `preview.html` to try the phone, 14-inch laptop, or 24-inch monitor view. Click Use without frame, or open `index.html`, for the full browser window.

Keep the files and `fonts` folder together. No install, server, or `.env` needed.

## Make a note

Cornell notes starts with Notes on the left, Details on the right, and Summary below. Sections stack on smaller screens. Start from also has To-do list and Class notes. Click a color circle to change the palette.

Type something, then click Tear off & save or press Ctrl / Cmd + Enter. The note lands in Inbox, and a fresh Cornell note is ready. Your unfinished draft saves as you type.

New field adds a section. Rename any field to something like Questions or Tasks. Fields with the same name share a column in My notebook; suggestions help you reuse names.

Click Draw to sketch with a mouse, finger, or stylus, and Type to write again. Both stay saved. Undo stroke removes the last drawn line.

## Find it again

In My notebook, search, pin, or open a note. Collections work like folders. Click Save changes after editing; closing the editor first drops those edits.

Show related sections makes cards from the same note pulse across columns. Click the button again to stop. Opening any card edits the whole note.

Deleted something by mistake? Click Undo, or go to Recently Deleted and click Restore. Text, sketches, collection, and reminder come back together.

To reuse a setup, open a saved note and click Save as template. Name it, then choose it under Start from. It keeps the layout, field names, and colors, with empty fields.

## Set a reminder

Click Remind me above the title, then use the date and time buttons. The reminder starts at right now; change it before saving.

Due reminders show a message and badge inside Noteable, with no sound or system notification. If the page is closed, overdue reminders appear when you return. Find them under Reminders and mark them done there.

## A few things to know

Theme offers Dark, Light, or Grayscale. Grayscale changes the display without changing saved note colors. Your choice stays saved and carries through the device previews.

Sign in and Sign up are just demo forms. Use made-up details if you try them. They don't create accounts, send anything, or save what you type.

Your notes stay in this browser on this device. They don't sync anywhere. Clearing browser data deletes your notes, drafts, templates, and Recently Deleted notes.

Press N to jump to Quick capture when you're not typing. Escape closes a popup. Help / FAQ has a quick rundown.
