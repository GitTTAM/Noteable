# Noteable

Made by KBM for our class project. A simple place to write notes, draw, and set reminders.

## Get started

[Download Noteable (.zip)](https://github.com/GitTTAM/Noteable/archive/refs/heads/main.zip), unzip it, and open `index.html`.

Open `preview.html` to try different device sizes. Keep the files and `fonts` folder together. No installation needed.

## Using it

- Write or draw a note, then click Tear off & save.
- Use Start from for templates and New field for extra sections.
- Find, edit, and organize notes in My notebook.
- Click Remind me to add a reminder. Alerts appear inside the app.

Help / FAQ has more details.

## Your notes

Notes stay in this browser on this device. Use Backup to download or restore a copy. Clearing browser data deletes your local notes.

Sign in and Sign up are demos. They don't create accounts or save your details.
